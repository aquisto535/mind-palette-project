## 🔰 초심자를 위한 개념 요약

영상 처리는 기본적으로 **"컴퓨터가 이미지를 숫자로 보고, 수학을 이용해 원하는 대로 조작하는 과정"입니다.

### 1. 기초 다지기 (화질 보정) - 1월 과정
우리가 사진 보정 앱에서 흔히 하는 작업들입니다. 컴퓨터에게는 픽셀(점) 하나의 값을 더하거나 곱하는 단순 산수입니다.
- **밝기/명암비 조절**: 영상의 모든 점에 숫자를 더하면(밝기) 전체적으로 환해지고, 숫자를 곱하면(명암비) 밝은 건 더 밝게, 어두운 건 더 어둡게 되어 선명해집니다.
- **히스토그램**: "이 사진에 밝은 점이 몇 개, 어두운 점이 몇 개 있지?"를 막대그래프로 그린 것입니다. 한쪽으로 쏠려 있다면 사진이 너무 어둡거나 밝다는 뜻이므로, 이를 평평하게 펴주면(평활화) 선명한 사진이 됩니다.

### 2. 영상 합치기 & 자르기 (산술/논리 연산) - 2월 1주차
두 장의 이미지를 겹치거나 특정 부분만 오려내는 작업입니다.
- **덧셈/뺄셈**: 두 사진을 겹쳐서 유령처럼 보이게(합성) 하거나, 배경 없는 사진에서 배경을 뺄 때 사용합니다. 틀린 그림 찾기(차이 연산)도 이 원리입니다.
- **논리 연산 (AND/OR)**: 포토샵의 '마스크' 기능과 같습니다. 검은색 종이(0)에 구멍을 뚫어(1) 사진 위에 덮으면 구멍 난 부분만 보이는 원리입니다.

### 3. 필터링 (흐리게 vs 선명하게) - 2월 2주차
주변 픽셀값들을 참고해서 현재 픽셀을 바꾸는 기술입니다.
- **블러(Blur)**: 나만의 값을 줄이고 주변 친구들의 평균값을 따라가는 것입니다. 튀는 잡티(노이즈)가 사라지고 이미지가 부드러워집니다.
- **샤프닝(Sharpening)**: 나와 주변의 차이를 더 과장하는 것입니다. 경계선이 뚜렷해져서 이미지가 날카로워집니다.

### 4. 모양 바꾸기 (기하학적 변환) - 2월 3주차
종이를 오려서 돌리거나 늘리는 작업입니다.
- **리사이즈/회전**: 크기를 바꾸거나 각도를 돌립니다.
- **투시 변환**: 비스듬하게 찍힌 문서 사진을 스캔한 것처럼 정면으로 펴주는 기술입니다. (스캐너 앱의 핵심 원리)

### 5. 다른 시각으로 보기 (주파수 영역) - 2월 4주차
이미지를 점(픽셀)들의 집합이 아니라 **물결(파동)의 합으로 봅니다.
- **푸리에 변환**: 복잡한 사진을 단순한 물결 무늬들로 분해합니다.
- **용도**: 규칙적인 노이즈(빗살무늬 등)를 제거하거나, 매우 빠른 연산이 필요할 때 사용합니다. 초심자에게는 가장 어려운 개념이니 "이미지를 성분별로 분해한다" 정도로만 이해해도 좋습니다.

### 6. 색상 다루기 (컬러 처리) - 3월
컴퓨터는 색을 어떻게 숫자로 표현할까요?
- **RGB**: 빛의 3원색(빨강, 초록, 파랑)을 섞습니다. 모니터 출력용입니다.
- **HSV**: **색상(H), 채도(S), 명도(V)**로 나눕니다. "빨간색 공을 찾아줘"라고 할 때 컴퓨터에게 가장 시키기 좋은 방식입니다. (빨강의 범위만 지정하면 되니까요)

### 7. 물체 분리하기 (영상 분할) - 3월
배경과 물체를 떼어내는 작업입니다.
- **이진화 (Thresholding)**: 가장 단순한 방법입니다. "밝기가 128 이상이면 흰색, 아니면 검은색"으로 딱 잘라 흑백 영상으로 만듭니다.
- **윤곽선 검출**: 물체의 테두리 선을 따냅니다. 이 선의 길이나 면적을 구해서 크기를 잴 수 있습니다.

### 8. 모양 다듬기 (모폴로지) - 3월
이진화된 흑백 그림을 다듬는 과정입니다.
- **침식/팽창**: 물체를 깎아내거나(침식) 살을 붙이는(팽창) 작업입니다.
- **용도**: 글자 획이 끊어졌을 때 이어주거나, 배경의 자잘한 점(노이즈)들을 없앨 때 사용합니다.

### 9. 물체 찾기 & 특징점 (고급 단계) - 3월
이제 단순 변경이 아니라 "이게 무엇이고 어디에 있나?"를 판단합니다.
- **템플릿 매칭**: 월리를 찾아라와 같습니다. 작은 그림(월리)을 큰 그림 위에서 훑어가며 똑같은 부분을 찾습니다.
- **코너/특징점(Keypoint)**: 사진에서 뾰족한 모서리나 유니크한 점을 찾습니다.
- **매칭**: 두 사진에서 같은 특징점을 연결합니다. 파노라마 사진(여러 장 이어 붙이기)을 만들 때 서로 겹치는 부분을 찾는 핵심 기술입니다.

## 1. 기초 영상 처리 (1월)

| 영상 기능 | OpenCV 함수 | 영상처리 알고리즘 | 수학적 수식 | 사용상황 | 최적화 기법 |
|:---|:---|:---|:---|:---|:---|
| **밝기 조절** | `src.convertTo(dst, -1, 1.0, beta)` | 픽셀값 일정량 증감 | `dst = src + n` | 저조도/과노출 영상 보정, 전체적으로 어둡거나 밝을 때 | LUT 사전 계산, 포화연산 `saturate_cast` |
| **명암비 조절** | `src.convertTo(dst, -1, alpha, beta)` | 128 기준 확장/축소 | `dst = src + (src-128)×α` | 흐릿한 영상 선명화, 명암비 낮은 저대비 영상 | LUT 활용, alpha 값 범위 제한 (0.5~3.0) |
| **감마 보정** | `LUT(src, lut, dst)` | 비선형 밝기 곡선 변환 | `dst = 255×(src/255)^(1/γ)` | 모니터 보정(γ=2.2), 야간영상 개선(γ<1), 과노출 억제(γ>1) | LUT로 pow() 연산 회피, 미리 계산 후 재사용 |
| **영상 반전** | `bitwise_not(src, dst)` | 픽셀값 반전 | `dst = 255 - src` | 네거티브 효과, 이진영상 분석 | 벡터화 가능, 단순 연산으로 매우 빠름 |
| **히스토그램 계산** | `calcHist(images, channels, mask, hist, histSize, ranges)` | 밝기 빈도 분포 계산 | `h[i] = Σ δ(pixel=i)` | 영상 품질 분석, 밝기 분포 파악, 전처리 방향 결정 | 메모리 지역성, 배열 접근 최적화 |
| **히스토그램 스트레칭** | 직접 구현 필요 | 최소/최대값으로 선형 확장 | `dst = (src-min)×255/(max-min)` | 좁은 밝기 범위를 전체 범위로 확장, 저대비 개선 | LUT 생성 후 적용, min/max는 한 번만 계산 |
| **히스토그램 평활화** | `equalizeHist(src, dst)` | CDF 기반 균등 분포 변환 | `dst = CDF[src]×255/total` | 자동 대비 개선, 명암비 최적화, 의료영상 품질 향상 | LUT로 CDF 사전 계산, O(N) 단일 패스 |

## 2. 산술 및 논리 연산 (2월 1주차)

| 영상 기능 | OpenCV 함수 | 영상처리 알고리즘 | 수학적 수식 | 사용상황 | 최적화 기법 |
|:---|:---|:---|:---|:---|:---|
| **영상 덧셈** | `add(src1, src2, dst)` | 포화연산 덧셈 | `dst = saturate(src1+src2)` | 다중 노출 합성, 밝기 증가, 영상 누적 | SIMD `_mm_adds_epu8()`, 포화연산 하드웨어 가속 |
| **영상 뺄셈** | `subtract(src1, src2, dst)` | 포화연산 뺄셈 | `dst = saturate(src1-src2)` | 배경 제거, 차이 분석, 프레임 간 변화 | SIMD, 부호 있는 연산 시 주의 |
| **절대 차이** | `absdiff(src1, src2, dst)` | 순서 무관 절대 차이 | `dst = |src1-src2|` | 움직임 감지, 배경 차분, 변화 감지, 침입 탐지 | 비트 연산으로 조건 분기 최소화 |
| **가중 평균 (알파 블렌딩)** | `addWeighted(src1, α, src2, β, γ, dst)` | 투명도 기반 합성 | `dst = α×src1 + β×src2 + γ` | 페이드 효과, 워터마크 삽입, HDR 합성, UI 반투명 | 고정소수점 연산, 16비트 중간 연산 |
| **논리곱 (AND)** | `bitwise_and(src1, src2, dst, mask)` | 비트 AND 연산 | `dst = src1 & src2` | 마스킹, ROI 추출, 특정 영역만 처리 | 비트 연산은 매우 빠름, SIMD 적용 가능 |
| **논리합 (OR)** | `bitwise_or(src1, src2, dst)` | 비트 OR 연산 | `dst = src1 | src2` | 영상 결합, 다중 ROI 통합, 오버레이 | 벡터 연산, 메모리 연속성 |
| **배타적 논리합 (XOR)** | `bitwise_xor(src1, src2, dst)` | 비트 XOR 연산 | `dst = src1 ^ src2` | 차이점 강조, 암호화, 이진영상 비교 | 단순 비트 연산, 최적화 용이 |
| **논리 부정 (NOT)** | `bitwise_not(src, dst)` | 비트 NOT 연산 | `dst = ~src` | 반전, 마스크 여집합 생성 | 벡터화 가능, 매우 빠름 |

## 3. 공간적 필터링 (2월 2주차)

| 영상 기능 | OpenCV 함수 | 영상처리 알고리즘 | 수학적 수식 | 사용상황 | 최적화 기법 |
|:---|:---|:---|:---|:---|:---|
| **평균값 필터 (박스 필터)** | `blur(src, dst, Size(k,k))` | 이웃 픽셀 평균 | `dst = (1/k²)Σkernel×src` | 가우시안 노이즈 제거, 단순 블러링, 빠른 스무딩 | 적분 영상(integral image) 활용 시 O(1) |
| **가우시안 필터** | `GaussianBlur(src, dst, Size(k,k), σ)` | 2D 가우시안 분포 가중 평균 | `G(x,y) = (1/2πσ²)e^(-(x²+y²)/2σ²)` | 고품질 노이즈 제거, 자연스러운 블러, 전처리 | 분리형(1D×1D) 구현으로 O(k²)→O(2k), SIMD |
| **미디언 필터** | `medianBlur(src, dst, ksize)` | 이웃 픽셀 중간값 선택 | `dst = median(neighborhood)` | 소금&후추 노이즈 특화 제거, 에지 보존하며 노이즈 제거 | quickselect O(n), 작은 커널은 히스토그램 기법 |
| **양방향 필터** | `bilateralFilter(src, dst, d, σColor, σSpace)` | 거리+밝기 차이 가중 평균 | `w = e^(-dist²/2σ²space)×e^(-ΔI²/2σ²color)` | 에지 보존 스무딩, 세부사항 유지 노이즈 제거, 카툰 효과 | LUT로 지수 함수 사전 계산, 공간 가중치 재사용 |
| **샤프닝 (언샤프 마스킹)** | `addWeighted(src, 1.5, blurred, -0.5, 0, dst)` | 원본 + α×(원본-블러) | `dst = src + α×(src-blur)` | 흐릿한 영상 선명화, 인물 사진 보정, 텍스트 가독성 향상 | 가우시안 블러 재사용, 메모리 임시 버퍼 최소화 |
| **커스텀 필터 (컨볼루션)** | `filter2D(src, dst, -1, kernel, Point(-1,-1), delta)` | 임의 커널 컨볼루션 | `dst = Σkernel×src + delta` | 엠보싱, 에지 검출, 사용자 정의 필터 | SIMD, 경계 처리 최적화 (BORDER_REFLECT) |
| **박스 필터** | `boxFilter(src, dst, -1, Size(k,k))` | 정규화 옵션 있는 평균 | `dst = Σsrc / (정규화 여부)` | 단순 평균, 빠른 블러, 적분 영상 전처리 | 적분 영상으로 O(1) 시간 복잡도 |

## 4. 기하학적 변환 (2월 3주차)

| 영상 기능 | OpenCV 함수 | 영상처리 알고리즘 | 수학적 수식 | 사용상황 | 최적화 기법 |
|:---|:---|:---|:---|:---|:---|
| **크기 변환 (리사이즈)** | `resize(src, dst, Size(w,h), 0, 0, INTER_LINEAR)` | 보간법 기반 리샘플링 | 좌표 스케일 변환 + 보간 | 썸네일 생성, 해상도 조정, 다중 스케일 처리 | 분리형 보간(수평→수직), INTER_AREA는 축소 최적화 |
| **어파인 변환 (3점)** | `M = getAffineTransform(src3pts, dst3pts)`<br>`warpAffine(src, dst, M, dsize)` | 3점 대응 연립방정식 해법 | `[x',y',1] = M[2×3]×[x,y,1]` | 회전+이동+스케일 조합, 문서 정렬, 객체 정합 | LU분해로 안정적 해법, 역변환 행렬 미리 계산 |
| **회전 변환** | `M = getRotationMatrix2D(center, angle, scale)`<br>`warpAffine(src, dst, M, dsize)` | 회전 행렬 생성 + 적용 | `M = [cosθ -sinθ tx; sinθ cosθ ty]` | 영상 회전, 각도 보정, 자세 정렬 | 삼각함수 한 번만 계산, 고정소수점 연산 |
| **투시 변환 (4점)** | `M = getPerspectiveTransform(src4pts, dst4pts)`<br>`warpPerspective(src, dst, M, dsize)` | DLT 알고리즘, SVD 해법 | `[x',y',w'] = M[3×3]×[x,y,1]`<br>`x'final = x'/w'` | 문서 스캔 보정, 원근 왜곡 제거, AR 마커 정합 | DLT+SVD로 안정적 해, 동차좌표 정규화 |
| **플립 (상하/좌우 반전)** | `flip(src, dst, flipCode)` | 축 기준 대칭 변환 | `flipCode: 0=상하, 1=좌우, -1=상하좌우` | 거울 효과, 데이터 증강, 카메라 방향 보정 | 메모리 복사만, 매우 빠름, 포인터 조작 가능 |
| **전단 변환 (Shear)** | `warpAffine(src, dst, shearMatrix, dsize)` | 한 축 방향 밀기 | `[x',y'] = [1 λ; 0 1]×[x,y]` | 기울임 효과, 시각 왜곡, 특수 효과 | 어파인 변환의 특수 케이스, 역변환 간단 |

## 5. 주파수 영역 처리 (2월 4주차)

| 영상 기능 | OpenCV 함수 | 영상처리 알고리즘 | 수학적 수식 | 사용상황 | 최적화 기법 |
|:---|:---|:---|:---|:---|:---|
| **푸리에 변환 (DFT)** | `dft(src, dst, flags)` | FFT (Cooley-Tukey) 알고리즘 | `F(u,v) = ΣΣ f(x,y)e^(-j2π(ux/M+vy/N))` | 주파수 분석, 주기적 노이즈 검출, 압축 기초 | Radix-2/3/5 FFT, 분리형 2D DFT (행→열), 비트 역순 |
| **역 푸리에 변환 (IDFT)** | `dft(src, dst, DFT_INVERSE | DFT_REAL_OUTPUT)` | FFT 역변환 | `f(x,y) = (1/MN)ΣΣ F(u,v)e^(j2π(ux/M+vy/N))` | 주파수 필터 후 공간 영역 복귀 | 정규화 인수 1/N, 동일 FFT 알고리즘 재사용 |
| **최적 DFT 크기** | `getOptimalDFTSize(size)` | 2,3,5 소인수 조합 찾기 | 2^a × 3^b × 5^c 형태 | FFT 성능 최대화 (2^n이 가장 빠름) | 미리 계산된 테이블, 성능 프로파일링 기반 |
| **주파수 스펙트럼 계산** | `magnitude(realpart, imagpart, magnitude)` | 복소수 크기 계산 | `|F| = √(Re² + Im²)` | 주파수 분포 시각화, 패턴 분석 | log 변환으로 동적 범위 압축 (1+log(mag)) |
| **위상 계산** | `phase(realpart, imagpart, phase)` | 복소수 위상 계산 | `∠F = atan2(Im, Re)` | 위상 정보 분석, 영상 재구성 | atan2 테이블화, 정밀도 vs 속도 트레이드오프 |
| **저역 통과 필터** | `mulSpectrums()` + 가우시안 마스크 | 고주파 제거 | `H(u,v) = e^(-D²(u,v)/2D₀²)` | 노이즈 제거, 블러링, 세부사항 제거 | 가우시안 커널 사전 생성, 중앙 대칭성 활용 |
| **고역 통과 필터** | `1 - 저역통과 필터` | 저주파 제거 | `H(u,v) = 1 - e^(-D²(u,v)/2D₀²)` | 에지 강조, 샤프닝, 경계선 검출 | 저역 통과 결과 재사용, 메모리 효율성 |
| **대역 저지 필터** | 주파수 도메인 마스킹 | 특정 주파수 대역 제거 | 특정 (u,v) 위치를 0으로 설정 | 주기적 노이즈 제거 (스캔 라인, 모아레) | 노이즈 주파수 자동 검출, 대칭 위치 동시 제거 |
| **FFT Shift** | 직접 구현 (사분면 교환) | DC 성분 중앙 이동 | 4개 사분면 대각선 교환 | 주파수 스펙트럼 시각화, 직관적 표현 | 메모리 복사, ROI 활용으로 최소화 |

### 주파수 필터 vs 공간 필터 비교

| 특성                   | 공간 필터             | 주파수 필터            |
| :------------------- | :---------------- | :---------------- |
| **계산 복잡도**           | O(N²M²) (M=커널 크기) | O(N²logN)         |
| **큰 커널 (15×15 이상)**  | 매우 느림             | 빠름 (FFT 우위)       |
| **작은 커널 (3×3, 5×5)** | 빠름                | 느림 (오버헤드)         |
| **직관성**              | 높음 (픽셀 단위 이해)     | 낮음 (주파수 개념 필요)    |
| **전역 처리**            | 어려움               | 용이함               |
| **주기적 노이즈**          | 제거 불가             | 특정 점 제거로 해결       |
| **사용 권장**            | 일반 필터링, 실시간       | 대형 필터, 주기 노이즈, 분석 |

## 7. 영상 분할 (3월)

| 영상 기능 | OpenCV 함수 | 영상처리 알고리즘 | 수학적 수식 | 사용상황 | 최적화 기법 |
|:---|:---|:---|:---|:---|:---|
| **단순 임계값 이진화** | `threshold(src, dst, thresh, maxval, THRESH_BINARY)` | 전역 임계값 비교 | `dst = src>T ? 255 : 0` | 명확한 배경/전경, 고정 조명, 단순 분할 | 벡터화, LUT (여러 이미지 동일 T) |
| **적응 임계값 이진화** | `adaptiveThreshold(src, dst, maxval, method, type, blockSize, C)` | 지역 블록별 임계값 | `T(x,y) = mean(block) - C` | 조명 변화 큰 영상, 문서 스캔, 그림자 있는 장면 | 적분 영상으로 블록 평균 O(1), 병렬화 |
| **Otsu 이진화** | `threshold(src, dst, 0, 255, THRESH_BINARY | THRESH_OTSU)` | 클래스 간 분산 최대화 | `T* = argmax σ²between(T)` | 자동 임계값, 이봉 히스토그램, 객체/배경 명확 | 히스토그램 기반 O(256), 한 번만 계산 |
| **반복 임계값 (직접 구현)** | 직접 구현 | 평균의 중간값 반복 | `T(k+1) = (μ₁+μ₂)/2` | 이봉 분포, 자동 임계값, Otsu 대안 | 5-10회 수렴, 히스토그램 재사용 |
| **레이블링 (2-pass)** | `connectedComponents(src, labels, connectivity)` | 등가 테이블 + 2번 스캔 | Union-Find 자료구조 | 객체 개수 세기, 개별 객체 분석, Blob 검출 | Union-Find 경로 압축, 4/8연결성 선택 |
| **레이블링 (통계)** | `connectedComponentsWithStats(src, labels, stats, centroids)` | 2-pass + 면적/중심 계산 | 레이블별 면적, 바운딩박스, 중심 | 객체 크기 필터링, 위치 기반 분석, 형태 분류 | 한 번에 통계 계산, 별도 반복 불필요 |
| **외곽선 검출** | `findContours(src, contours, hierarchy, mode, method)` | 경계 추적 (Suzuki-85) | Moore-Neighbor Tracing | 객체 형상 분석, 면적/둘레 계산, 형태 매칭 | 계층 구조 활용, 근사화로 점 개수 감소 |
| **외곽선 근사화** | `approxPolyDP(contour, approx, epsilon, closed)` | Douglas-Peucker 알고리즘 | epsilon 거리 내 점 제거 | 다각형 근사, 꼭지점 추출, 메모리 절약 | 재귀 대신 반복, epsilon 값 최적화 (0.01-0.05) |
| **외곽선 면적** | `contourArea(contour, oriented)` | Shoelace 공식 (Green 정리) | `A = 0.5|Σ(x_i y_(i+1) - x_(i+1) y_i)|` | 객체 크기 측정, 필터링 (너무 작은/큰 것 제거) | 단순 루프, O(n) |
| **외곽선 둘레** | `arcLength(contour, closed)` | 유클리드 거리 누적 | `L = Σ√((x_(i+1)-x_i)²+(y_(i+1)-y_i)²)` | 객체 복잡도, 형상 비율 (면적/둘레²) | 정수 연산 근사, sqrt 테이블화 |
| **바운딩 박스** | `boundingRect(contour)` | 최소/최대 좌표 탐색 | `(min_x, min_y, max_x-min_x, max_y-min_y)` | 객체 위치, ROI 설정, 충돌 검사 | 단일 패스, O(n) |
| **최소 회전 사각형** | `minAreaRect(contour)` | 회전 각도 포함 최소 사각형 | Rotating Calipers 알고리즘 | 방향성 있는 객체, 차량 각도, 문서 정렬 | 볼록 껍질 먼저 계산, O(n log n) |

| :------------------ | :----------------------------------------------- | :------------- | :------------------------------------------- | :-------------------------- | :----------------------- |
| **침식 (Erosion)**    | `erode(src, dst, kernel, anchor, iterations)`    | 최솟값 선택 (구조 요소) | `dst = min{src(x+x',y+y')}`                  | 노이즈 제거, 객체 축소, 연결 끊기        | 분리형 SE (사각형), 3×3 특별 최적화 |
| **팽창 (Dilation)**   | `dilate(src, dst, kernel, anchor, iterations)`   | 최댓값 선택 (구조 요소) | `dst = max{src(x+x',y+y')}`                  | 홀 메우기, 객체 확대, 연결 강화         | 분리형 SE, 반지름 증가 시 여러번 3×3 |
| **열기 (Opening)**    | `morphologyEx(src, dst, MORPH_OPEN, kernel)`     | 침식 → 팽창        | `A ∘ B = (A ⊖ B) ⊕ B`                        | 배경 잡음 제거, 돌출부 제거, 작은 객체 제거  | 침식/팽창 각각 최적화, 임시 버퍼 재사용  |
| **닫기 (Closing)**    | `morphologyEx(src, dst, MORPH_CLOSE, kernel)`    | 팽창 → 침식        | `A • B = (A ⊕ B) ⊖ B`                        | 홀 메우기, 오목 부분 채우기, 끊어진 선 연결  | 팽창/침식 순서 최적화, 메모리 효율     |
| **형태학적 그래디언트**      | `morphologyEx(src, dst, MORPH_GRADIENT, kernel)` | 팽창 - 침식        | `(A ⊕ B) - (A ⊖ B)`                          | 외곽선 추출, 경계 검출, 에지 강조        | 팽창/침식 병렬 계산, 차이만 저장      |
| **탑햇 (Top Hat)**    | `morphologyEx(src, dst, MORPH_TOPHAT, kernel)`   | 원본 - 열기        | `A - (A ∘ B)`                                | 밝은 세부사항 추출, 배경 제거, 작은 객체 강조 | 열기 결과 재사용, 메모리 효율        |
| **블랙햇 (Black Hat)** | `morphologyEx(src, dst, MORPH_BLACKHAT, kernel)` | 닫기 - 원본        | `(A • B) - A`                                | 어두운 세부사항 추출, 홀/틈 강조         | 닫기 결과 재사용                |
| **히트오어미스**          | `morphologyEx(src, dst, MORPH_HITMISS, kernel)`  | 패턴 매칭 (두 SE)   | 전경 SE 일치 & 배경 SE 불일치                         | 특정 패턴 검출, 끝점/분기점 찾기         | 조기 종료, 비트 연산             |
| **구조 요소 생성**        | `getStructuringElement(shape, size)`             | 사각형/십자/원형 SE   | `MORPH_RECT`, `MORPH_CROSS`, `MORPH_ELLIPSE` | 연산별 최적 SE 선택                | 사각형이 가장 빠름, 원형은 등방성      |

### 모폴로지 연산 선택 가이드

| 문제 상황 | 추천 연산 | 커널 크기 | 주의사항 |
|:---|:---|:---|:---|
| 배경에 잡음 (흰 점) | 열기 (Opening) | 3×3 또는 5×5 | 객체 크기보다 작게 |

| **BFMatcher (전수 조사)** | `BFMatcher(normType, crossCheck)`<br>`.match()` / `.knnMatch()` | 모든 조합 거리 계산 | `d = ||desc1 - desc2||` (L2 or Hamming) | 소규모 특징점, 정확한 매칭 필요 | SIMD Hamming 거리 (이진), crossCheck 필터 |
| **FlannBasedMatcher** | `FlannBasedMatcher(indexParams, searchParams)` | KD-Tree / LSH 근사 탐색 | Approximate Nearest Neighbors | 대규모 특징점 (1000+), 속도 우선 | SIFT/SURF는 KD-Tree, ORB는 LSH |
| **Lowe's Ratio Test** | `knnMatch(k=2)` 후 ratio 비교 | 1st/2nd 거리 비율 | `d1/d2 < ratio` (0.7~0.8) | 매칭 품질 향상, 오매칭 제거 | 벡터화, 병렬 처리 |
| **Cross Check** | `BFMatcher(crossCheck=True)` | 양방향 매칭 일치 확인 | `match(A→B) && match(B→A)` | 신뢰도 높은 매칭만 선택 | BFMatcher 내부 최적화, 단일 패스 |
| **RANSAC 호모그래피** | `findHomography(srcPts, dstPts, RANSAC, threshold)` | 무작위 샘플링 + 컨센서스 | 반복: 4점 샘플→H 계산→inlier 개수 | 아웃라이어 제거, 평면 객체 매칭 | 적응적 반복 횟수, 조기 종료 |
| **RANSAC 펀더멘탈** | `findFundamentalMat(pts1, pts2, FM_RANSAC)` | 에피폴라 제약 기반 | 7/8점 알고리즘 + RANSAC | 스테레오 비전, 3D 재구성, 카메라 모션 | 정규화 8점 알고리즘, LMedS 대안 |
| **원근 변환 (매칭 기반)** | `perspectiveTransform(srcPts, dstPts, H)` | 호모그래피 행렬 적용 | `[x',y',w'] = H×[x,y,1]` | 객체 위치 변환, 바운딩 박스 매핑 | 벡터화, 동차좌표 정규화 한 번 |
| **매칭 시각화** | `drawMatches(img1, kp1, img2, kp2, matches, outImg)` | 대응점 선으로 연결 | - | 디버깅, 품질 확인, 프레젠테이션 | 매칭 개수 제한 (상위 N개), 색상 구분 |
| **호모그래피 기반 객체 검출** | `findHomography()` + `perspectiveTransform()` | 매칭 → H → 코너 변환 | 4개 코너 투영 → 바운딩 박스 | 객체 위치 추정, AR 마커 추적 | inlier 비율 체크 (>50%), 적응적 임계값 |

### 매칭 품질 향상 기법

| 기법 | 방법 | 효과 | 언제 사용 |
|:---|:---|:---|:---|
| **Distance Filtering** | `d < threshold` | 먼 매칭 제거 | 항상 (기본) |
| **Lowe's Ratio Test** | `d1/d2 < 0.75` | 애매한 매칭 제거 | kNN 가능 시 (권장) |
| **Cross Check** | 양방향 일치 확인 | 일방적 매칭 제거 | BFMatcher 사용 시 |
| **RANSAC** | 기하학적 일관성 확인 | 아웃라이어 대량 제거 | 호모그래피/에피폴라 (필수) |
| **비율 임계값 조정** | 0.7~0.85 범위 | 정밀도↔재현율 조정 | 매칭 개수 부족/과다 시 |

### BFMatcher vs FlannBasedMatcher

| 특성 | BFMatcher | FlannBasedMatcher |
|:---|:---|:---|
| **알고리즘** | 전수 조사 (Brute-Force) | 근사 최근접 이웃 (ANN) |
| **정확도** | 100% 정확 | 근사 (98-99%) |
| **속도 (작은 집합)** | 빠름 | 느림 (오버헤드) |
| **속도 (큰 집합)** | 느림 O(n²) | 빠름 O(n log n) |
| **메모리** | 적음 | 많음 (색인 구조) |
| **SIFT/SURF** | NORM_L2 | KD-Tree (효과적) |
| **ORB (이진)** | NORM_HAMMING (빠름) | LSH (덜 효과적) |
| **CrossCheck** | 지원 | 미지원 |
| **권장 상황** | ORB, 소규모 (<500) | SIFT/SURF, 대규모 (1000+) |

## 📊 알고리즘 복잡도 및 성능 비교

### 시간 복잡도 요약

| 알고리즘 | 복잡도 | N 의미 | 비고 |
|:---|:---|:---|:---|
| **밝기 조절** | O(N) | 픽셀 수 | LUT 사용 시 O(N) |
| **히스토그램 계산** | O(N) | 픽셀 수 | 단일 패스 |
| **히스토그램 평활화** | O(N+256) | 픽셀 수 | CDF 계산 O(256) |
| **가우시안 필터 (분리형)** | O(N×k) | 픽셀 수, 커널 크기 k | 2D는 O(N×k²) |
| **미디언 필터** | O(N×k²×log(k²)) | 픽셀 수, 커널 크기 | 정렬 또는 quickselect |
| **양방향 필터** | O(N×k²) | 픽셀 수, 커널 크기 | LUT로 지수 함수 최적화 |
| **어파인 변환** | O(N) | 출력 픽셀 수 | 역방향 매핑 + 보간 |
| **FFT (1D)** | O(N log N) | 데이터 크기 | Cooley-Tukey |
| **2D DFT** | O(N² log N) | N×N 영상 | 분리형 (1D×2) |
| **레이블링 (2-pass)** | O(N) | 픽셀 수 | Union-Find 최적화 |
| **외곽선 추적** | O(P) | 외곽선 점 개수 | Moore-Neighbor |
| **볼록 껍질** | O(n log n) | 외곽선 점 개수 | Graham Scan |
| **템플릿 매칭** | O(N×M) | 영상 크기 N, 템플릿 크기 M | FFT 방식은 O(N log N) |
| **FAST 코너** | O(N) | 픽셀 수 | 16점 비교, 조기 종료 |
| **Harris 코너** | O(N) | 픽셀 수 | Sobel + 창 연산 |
| **SIFT 검출** | O(N log N) | 픽셀 수 | 피라미드 + DoG |
| **BFMatcher** | O(n×m) | 특징점 개수 n, m | 전수 조사 |
| **FLANN Matcher** | O(n log m) | 특징점 개수 n, m | KD-Tree 또는 LSH |

## 💡 핵심 최적화 기법 총정리

### 1. 메모리 접근 최적화
- **행 우선 순서**: 연속된 메모리 접근으로 캐시 히트율 극대화
- **연속성 확인**: `img.isContinuous()`로 1D 접근 가능 여부 확인
- **ROI 활용**: 필요한 영역만 처리, 메모리 공유로 복사 회피

### 2. 알고리즘 선택 최적화
- **분리형 필터**: 2D 컨볼루션을 1D×2로 분해 (O(k²) → O(2k))
- **적분 영상**: 박스 필터, Haar 특징 O(1) 계산
- **LUT (Look-Up Table)**: 복잡한 함수(pow, exp, log)를 테이블 조회로 대체

### 3. 하드웨어 가속
- **SIMD (SSE/AVX)**: 8~16픽셀 동시 처리
- **멀티스레딩**: `parallel_for_`로 행 단위 병렬화
- **GPU 가속**: [[CUDA]] 모듈 (`cv::cuda`) 사용 시 10~100배 향상

### 4. 데이터 타입 최적화
- **고정소수점**: 부동소수점 연산을 정수 연산으로 변환
- **타입 선택**: CV_8U (일반), CV_32F (중간 계산), CV_16U (의료)
- **포화 연산**: `saturate_cast<uchar>()`로 범위 안전 보장

### 5. 조기 종료 및 필터링
- **임계값 기반**: 조건 불만족 시 즉시 스킵
- **캐스케이드 구조**: 단계별 거부로 계산량 감소 (Haar Cascade)
- **Non-Max Suppression**: 중복 검출 제거, 최댓값만 유지

## 🎓 학습 로드맵 및 프로젝트 아이디어

### 초급 (1-2개월)
1. **문서 스캐너 앱**: 경계 검출 + 투시 변환 + 이진화
2. **얼굴 검출 프로그램**: Haar Cascade 활용
3. **색상 필터 앱**: HSV 변환 + inRange + 마스킹
4. **사진 필터 앱**: 가우시안 블러, 샤프닝, 세피아 효과

### 중급 (3-4개월)
1. **QR 코드 스캐너**: 검출 + 디코딩 + 정보 추출
2. **파노라마 사진 생성기**: SIFT/ORB 매칭 + 스티칭
3. **객체 추적 프로그램**: 옵티컬 플로우 + 칼만 필터
4. **차선 검출 시스템**: Canny + Hough + ROI

### 고급 (5-6개월)
1. **얼굴 인식 시스템**: 검출 + 정렬 + 기술자 + 매칭
2. **3D 재구성**: 스테레오 비전 + 시차 맵 + 포인트 클라우드
3. **실시간 AR 앱**: 마커 검출 + 포즈 추정 + 가상 객체 렌더링
4. **영상 압축 프로그램**: DCT + 양자화 + 엔트로피 코딩
