# OpenCV 블러(Blur) 기술 비교 및 선택 가이드

본 문서는 이미지 처리에서 사용되는 주요 블러 필터들의 특성을 분석하고, 프로젝트 상황에 맞는 최적의 필터를 선택하기 위한 지침을 제공합니다.

---

## 1. 블러 필터별 분석 (First Principles)

### A. Average Blur (균일 블러)
*   **함수**: `cv::blur()`
*   **원리**: 커널 영역 내 모든 픽셀의 단순 산술 평균을 구함.
*   **장점**: 연산 속도가 가장 빠름.
*   **단점**: **에지(Edge) 파괴가 가장 심함.** 선명도가 중요한 분석에는 부적합.
*   **적용**: 연산 자원이 극도로 제한된 환경에서의 단순 노이즈 제거.

### B. Gaussian Blur (가우시안 블러)
*   **함수**: `cv::GaussianBlur()`
*   **원리**: 중앙 픽셀에 높은 가중치를 주는 가우시안 분포(종 모양) 기반 가중 평균.
*   **장점**: 디지털 이미지의 일반적인 노이즈(가우시안 노이즈) 제거에 탁월하며 자연스러움.
*   **단점**: 여전히 에지가 약간 흐려짐.
*   **적용**: **에지 검출(Canny)의 전처리 단계**, 범용적인 이미지 품질 개선.

### C. Median Blur (중간값 블러)
*   **함수**: `cv::medianBlur()`
*   **원리**: 주변 픽셀들을 정렬하여 중간값을 선택 (비선형 필터).
*   **장점**: **솔트 앤 페퍼(salt-and-pepper) 노이즈 제거에 탁월**하며, 에지 선명도를 비교적 잘 유지함.
*   **단점**: 커널 크기가 커지면 연산 비용이 증가함.
*   **적용**: 스캔된 문서, 먼지가 많은 이미지, **필압 보존이 필요한 그림 분석.**

### D. Bilateral Filter (양방향 필터)
*   **함수**: `cv::bilateralFilter()`
*   **원리**: 거리 차이와 **픽셀 값(색상) 차이**를 동시에 고려하여 가중치를 계산.
*   **장점**: **에지를 완벽에 가깝게 보존**하면서 평면 영역의 노이즈만 제거.
*   **단점**: 연산량이 매우 많아 처리 속도가 가장 느림.
*   **적용**: 고해상도 초상화 보정, 에지 보존이 극도로 중요한 정밀 기하학적 분석.

## 2. 상황별 선택 매트릭스 (Selection Matrix)

| 제거 목표 | 우선순위 | 추천 필터 | 비고 |
| :--- | :---: | :--- | :--- |
| **전반적인 지직거림** | 속도/균형 | **Gaussian** | Canny 에지 검출 필수 전처리 |
| **튀는 점(소금/후추)** | 정확도 | **Median** | 선의 경계를 보호해야 할 때 |
| **속도가 최우선** | 성능 | **Average** | 실시간성이 극도로 중요할 때 |
| **에지 보존이 최우선** | 품질 | **Bilateral** | 속도보다 결과물의 품질이 중요할 때 |

## 3. Mind Palette 권장 전략

아동의 그림 분석에서는 **선의 형태(Shape)**와 **필압(Intensity)**이 모두 중요합니다.

1.  **기본 조합 (현재 적용 중)**:
    *   `GaussianBlur(5x5)` + `medianBlur(3)` 연쇄 적용.
    *   **이유**: 가우시안으로 전체적인 캔버스를 안정화하고, 메디안으로 선의 특징을 보호하며 잡점을 제거함.
2.  **정밀 분석 모드 (옵션)**:
    *   중요도가 높은 개별 객체 분석 시 `Bilateral Filter` 적용 검토.
